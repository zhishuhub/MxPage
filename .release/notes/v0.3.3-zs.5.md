- 不再卡住：网站响应超时、断网、繁忙时当场自动重试一次；还不行就标「没完成」并说清原因，点「继续生成」直接重新请求，不用再确认。画了一半的套也能点「继续生成」补齐缺的图。出图检查没来得及做完不算失败，图照常算完成，那张标「没检查」。
- 几套一起生成：设置 → 生成设置里选同时生成几套（默认 3 套，最多 6 套）；网站连续超时时自动少开几套，顺了再加回来。点「开始生成」后马上开出第一轮，只生成一套时直接打开那一套。
- 进度看得见：生成记录的卡片显示正在做哪一步（写文案、设计画面、画图 2/6、检查）和已用时间，还在排队的几套也显示出来。文案和画面一次写完，每套少等一轮。
- 生成记录可以多选：点「选择」后勾选或全选，批量导出、删除、没完成的接着生成；按「生成中 / 已完成 / 需处理」筛选，「加载更多」看更早的作品。删除时连同应用里存的图片一起删掉。
- 作品页：点图在应用里看大图，左右键翻页，可以直接不要、重画、改字重画；「上一套 / 下一套」连着看；发布文案里的违规词可以「一键改掉」。
- 手动生成也能自动导出（设置 → 生成设置，或开始生成按钮下方的勾选）。
- 选城市可以搜索，每个等级可以「全选这一级」；记住上次选的城市、模板和比例；开始前提示这次大约画几张图。
- 页头显示剩余额度，有新版本时页头直接提示，点了去网站下载。
- 去掉右下角原项目的任务队列浮窗；后台运行时有任务在跑每 5 秒推进一次，批量完成的通知点开直接到生成记录。

Windows 下载 exe 双击安装；macOS 下载 dmg，把 KTu 拖进「应用程序」，首次打开右键选「打开」（未签名）。
