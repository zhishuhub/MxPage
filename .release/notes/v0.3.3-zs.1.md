K图首个版本：按城市整理商K店名，自动生成抖音图文。

- 六个模板：城市商K排名、夯到拉排行榜、城市KTV怎么选、商K精选推荐、单个商K介绍、分区域商K整理。
- 批量生成：选城市或城市等级，一键按顺序生成多套图文；有问题的图可以丢弃，导出时跳过。
- 定时任务：每天、每周或每隔几小时自动轮换城市和模板生成，成品按「日期 / 城市 / 模板」存到输出文件夹；关窗缩到托盘后台运行，可开机自启。
- AI 服务用网站接入码一键接入，费用从网站余额扣除。

Windows 解压后运行 `KTu.exe`；macOS 解压后右键点 `KTu` 选「打开」（未签名）。
