K图 0.3.3-zs.4

- 模板可以改、可以新增：左侧新增「模板」页。内置六个模板可以直接改，改坏了能恢复默认；也可以新增或复制一个再改，自己新增的可以删除。每个模板填用几家店、随机还是轮换挑店、出几张图、每张图放什么。
- 提示词换成抖音商K专用的写法，画面风格不限，按模板内容自由发挥；模板里写了风格就照写的来。
- 出图检查做成开关（设置 → 出图检查）：打开时每张图画完让 AI 核对图上的字和你的检查要求，没通过的自动重画一次，还不合格标「需检查」；关掉后画完直接算完成。检查要求可以自己改、自己加。
- 作品页可以「改字重画」「重画这张」，旧图都留着可以换回去；发布标题、正文、话题标签可以直接改。
- 正文不再自动加「个人主观排名，仅供娱乐参考」。

Windows 下载 exe 双击安装；macOS 下载 dmg，把 KTu 拖进「应用程序」，首次打开右键选「打开」（未签名）。
